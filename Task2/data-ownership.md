# Владение данными

Роли ниже предлагаются к назначению. Для продуктовых данных розницы и МСБ владелец выбирается по бизнес-линии продукта; для общего клиентского профиля назначается один бизнес-владелец группы. Data Office координирует качество, ИТ эксплуатирует системы.

| Сущность | Data Owner | Data Steward | Producer | Consumer | Правила изменения | Обязательные проверки качества |
|---|---|---|---|---|---|---|
| Клиент | Владелец клиентских данных группы | Клиентский steward Data Office | CRM/Core → MDM | CRM, DWH, риск-менеджмент | Сотрудник обновляет подтверждённые данные в источнике; MDM собирает эталон; спорное слияние подтверждает steward | Тип лица, реквизиты, дубли, верификация контактов |
| Соответствие ID | Владелец клиентских данных группы | Клиентский steward Data Office | MDM | Integration Layer, CRM, DWH | Автосопоставление по утверждённым правилам; ручные merge/split с аудитом | Один активный общий ID на локальный ключ; история решений |
| Договор | Владелец соответствующего продукта | Steward договорных данных | Core/Cards/Loans | CRM, DWH, финансовый департамент | Уполномоченный сотрудник через процесс системы-мастера; условия версионируются | Участники и роли, даты, версия продукта/тарифа |
| Счёт | Владелец счётного продукта | Steward счетов | Core | Cards, Loans, DWH | Статусы через Core; остаток меняется проведением операций | Уникальность ключа, валюта, договор, остаток на срез |
| Карта | Владелец карточного продукта | Steward карточных данных | Cards | Core, CRM, DWH | Выпуск/блокировка через Cards | Токен, держатель, счёт, допустимый переход статуса |
| Кредит | Владелец кредитного продукта | Steward кредитных данных | Loans; Core для учёта | CRM, DWH, риск-менеджмент | Условия в Loans по согласованной процедуре; учёт корректируется в Core | Договор, график, валюта, сверка задолженности |
| Операция | Финансовый департамент | Steward учётных данных | Core; Cards/Loans дают контекст | DWH, BI, риск-менеджмент | Проведение/сторно в Core; опубликованный факт не удаляется | Исходный ключ, полнота проводок, суммы по банку/валюте/дате |
| Платёж | Владелец платёжного сервиса | Steward платёжных данных | Канал → платёжный модуль Core | Core, DWH, CRM | Авторизованный процесс исполнения; смена статуса по допустимым переходам | Идемпотентность, реквизиты, сумма/валюта, связь с исполнением |
| Продукт | Владелец продукта | Steward продуктового каталога | Продуктовая команда → MDM | CRM, Core/Cards/Loans, DWH | Утверждение версии владельцем, публикация через MDM | Канонический код, семейство, версия, исходные соответствия |
| Тариф | Владелец продукта | Steward тарифов | Продуктовая команда → MDM | Core/Cards/Loans, DWH | Изменение после согласования; отдельная версия с датой действия | Единицы ставок, интервалы, совместимость с продуктом |
| Обращение | Руководитель контактного центра | Steward обращений | CRM | Сотрудники обслуживания, DWH | Назначенный оператор меняет обращение в CRM | Клиент при идентификации, статусы, даты, обязательная тема |
| Справочное значение | Владелец предметного справочника | Назначенный steward справочника | Владелец → MDM | Все профильные системы, DWH | Согласование значения и маппинга, сохранение истории | Тип справочника, уникальность кода, интервалы действия |
| Документ | Владелец процесса, создавшего документ | Документный steward процесса | Исходное приложение | CRM/Core/Loans, реестр документов | Загрузка новой версии уполномоченным сотрудником; удаление по утверждённому сроку хранения | Хеш, версия, существование объекта и связи, класс доступа |
| Согласие | Владелец клиентских данных группы | Steward согласий | Канал → CRM | MDM, CRM-потребители, DWH | Фиксация получения/отзыва с доказательством; область действия сохраняется | Цель, версия текста, доказательство, время и применимость отзыва |
